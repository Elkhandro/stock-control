# stock-control / Складской Учёт

## Назначение

Приложение предназначено для автоматизации учёта остатков товаров на складе. Оно позволяет вести централизованный контроль наличия продукции, фиксировать поступление и отгрузку товаров, а также оперативно получать информацию о текущих остатках для предотвращения дефицита или излишков.

## Целевая аудитория

Кладовщики, менеджеры по закупкам, бухгалтеры материального стола и владельцы малого и среднего бизнеса, нуждающиеся в простом и быстром инструменте инвентаризации без использования сложных ERP-систем.

## Предметная область

Складская логистика и управление товарно-материальными запасами (ТМЦ). Область охватывает процессы хранения, идентификации товаров, учета их движения (приход/расход) и формирования отчетности по текущему состоянию склада.

## Основные сущности

- **Товар** (наименование, артикул, категория, единица измерения)
- **Складская операция** (приход или расход, дата, количество, комментарий)
- **Остаток** (текущее количество товара на складе, рассчитанное на основе операций)

## Основные функции

- **Приёмка товара:** Ввод данных о поступлении новой партии (увеличение остатка).
- **Отгрузка товара:** Списание товара со склада с проверкой достаточности остатка.
- **Просмотр остатков:** Вывод списка всех товаров и их текущего количества.
- **История операций:** Просмотр лога всех приходов и расходов для аудита.
